Spawn availability — the now-dominant wall

This is the lever that actually gates circle-2 time. The mechanism, measured in server/game.js:

  • Respawn tick every 25s; a dead creature returns in 25s normally.
  • Anti-camp throttle: a room with ≥14 respawns in a 5-min rolling window pushes the next respawn to +120s and emits "the hunting here has grown thin".
  • Quiet world has plenty (a probe saw a rat + silverfish present every look for 2 min). Starvation only appears when many agents share few rooms — exactly the crowded-world mode.
  • The throttle bites even a lone fast hunter: boost ×20 kills faster than 1/21s, so camping one room self-throttles.

Implication: in a clean one-agent-per-arena run, spawn availability is not the limiter — kill rate is. The zrmn run kept agents in distinct arenas yet still hit 24/h, which means the bound is the per-agent hunt cadence + how many creatures a room holds, not contention. The fix is arena spread (already done) plus raising per-room creature density for sweeps (DR_SPAWN_MULT).

Long-term goals

Near term — first circle-up active focus

  • Land circle 2 with the kaizen. Logic is built and engaging; the remaining work is upstream — kill rate and nav. Every run graded by shortfall-closure rate so variants stay comparable without the event.
  • Kill-rate to 50/h: arena spread (done) + DR_SPAWN_MULT density for sweep windows + tighter RT idle in the fight loop.
  • Kill the bazaar stall: make the origin-gated arrival + bazaar guard actually hold — agents must not re-drift once re-pathed.
  • Get the readiness gate to read expRanks so hall trips are intelligence-driven, not timer-driven.

Mid term — efficient circling machine

  • Variance collapse: median run within ~20% of best; kill regressions + nav wedges caught via sweeps.db trend tracking.
  • Circle 3–5 without redesign: script regeneration already retargets curricula; verify slot counts, ability unlocks, wider creature bands keep up unattended.
  • Variant graduation rule: a variant replaces baseline when it wins on shortfall-closure rate across ≥6 runs; losing variants dropped per the "no strength" rule.

Long term — generalizes to every guild

  • Circle 10 barbarian — full weapon ladder (club → short sword → cavalry sabre), armor progression, all four ability classes.
  • Per-guild kaizen kits: each guild gets its own signature-slot rules, train sets, fidelity checks. The circling kaizen is already guild-agnostic (it lives in buildCircleScript), so warmage inherits it once it can hunt — see the Warmage roadmap.
  • Fidelity ledger as acceptance criteria for all ten remaining guilds.
  • Continuous benchmarking: scheduled baseline runs flag pacing regressions before they compound.

Open risks & honest caveats

  • No circle-up has ever happened — the grade ladder and all pacing projections remain unvalidated against the actual event. Best recorded circle-2 is still the pre-kaizen 32.9 min.
  • Navigation still regresses: the town-strand breaker + bazaar guard fire but don't hold — half the agents end wedged at the bazaar. This is now the dominant non-spawn blocker.
  • Kill rate is the ceiling: boost ×20 already maxes per-kill exp; 24/h in zrmn means the exp-rank gate can't close in a 15-min window. Per-room creature density (DR_SPAWN_MULT) is the only lever left.
  • Run variance is wide (kills/hour spread ~2×) with few repeats; medians are thin. Kaizen A/Bs use one-variable changes for exactly this reason.
  • Measurement has repeatedly lied to us — truncated fidelity logs, mindstate omissions, latched wedge detectors. The DB + harness probes are ground truth; grep counts alone are not. Catalogued in sim architecture §7.
