# Whip command

_Automatically mirrored from Elanthipedia (2026-08-12)._

The '''{{tt|whip}} [[page type is::command]]''' used to attack your opponent with a [[:Category:Whips|whip]].

==Syntax==
* {{tt|whip}}
* {{tt|whip}} ''<target>''
* {{tt|whip}} ''<body part>''
* {{tt|whip}} ''<target> <body part>''
* {{tt|whip LEFT}}
* {{tt|whip LEFT}} ''<target>''
* {{tt|whip LEFT}} ''<body part>''
* {{tt|whip LEFT}} ''<target> <body part>''
