Unlocks additional shapes for a [[moonblade]] to act as different [[weapons]].

==Shaping==
Syntax: {{tt|shape moonblade to <shape>}}.

Roundtime to change the shape may take about 40 seconds.

The physical form of your moonblade can be shaped in one of these ways:
* '''WARDED'''      Disable the moonblade's attack messaging.
* '''UNWARDED'''    Reactivate the moonblade's attack messaging.
* '''BLUNT'''       [[Quarter Staff]], designed for swinging. Changes to a long <color> moonstaff.
* '''CURVED'''      [[Medium Edged]], designed for slicing. Changes to a ''curved'' <color> moonblade.
* '''HEAVY'''       [[Heavy Edged]], designed for slicing. Changes to a ''heavy'' <color> moonblade.
* '''HUGE'''        [[Twohanded Edged]], designed for slicing. Changes to a ''huge'' <color> moonblade.
* '''NARROW'''      [[Medium Edged]], designed for thrusting. Changes to a ''narrow'' <color> moonblade.
* '''NORMAL'''      [[Medium Edged]], designed for parrying. Changes to a <color> moonblade.
* '''SMALL'''       [[Light Edged]], designed for thrusting. Changes to a ''small'' <color> moonblade.
