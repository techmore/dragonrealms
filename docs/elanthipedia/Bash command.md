# Bash command

_Automatically mirrored from Elanthipedia (2026-08-12)._

The '''{{tt|bash}} [[page type is::command]]''' used to attack your opponent, is one of the specific combat maneuvers that make up weapon combos.

It is the blunt weapon equivalent of the {{com|chop}} command.

==Syntax==
* {{tt|BASH}}
* {{tt|BASH}} ''<target>''
* {{tt|BASH}} ''<body part>''
* {{tt|BASH}} ''<target> <body part>''
* {{tt|BASH LEFT}}
* {{tt|BASH LEFT}} ''<target>''
* {{tt|BASH LEFT}} ''<body part>''
* {{tt|BASH LEFT}} ''<target> <body part>''
