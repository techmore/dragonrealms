==Notes==
*Group buff that increases {{skill|scholarship}}.
*Decreases the time between teaching pulses for any class taught by someone affected by the spell.
**The only requirement for reduced class timers is that the teacher of a class must be affected by the spell. I.e. you do not need to be teaching or listening to the class.
**The base class pulse timer is 60 seconds between pulses.
**At minimum prep, the class pulse timer is 55 seconds between pulses, which is a 5 second reduction.
**At spell cap, the class pulse timer is 35 seconds between pulses, which is a 25 second reduction.
**The timer until the next class pulse is determined at the time the previous pulse happens, so this effect will not speed up the class until after a class pulse has occurred while under the effects of this spell.
*Can be {{com|cast}} {{tt|area}} if the [[Magical feats|Area Casting feat]] is known. This will affect all players in the room instead of just your group.
*Cannot be cast in extremely deep water.
* Associated with Air, but is not affected by the [[Spell_efficacy#Elemental_Efficacy|Elemental Efficacy]] system.
