# Augmentation skill

_Automatically mirrored from Elanthipedia (2026-08-12)._

{{RTOC}}
Augmentation is a new magic skill added in [[Dragonrealms 3.0]] as the primary skill check when casting spells that buff yourself or others. See the [[Magic|magic page]] for details on how to use and train Augmentation.
