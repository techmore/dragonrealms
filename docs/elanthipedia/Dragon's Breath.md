==Notes==
*Creates an effect that can be triggered using either {{com|spit}} or {{com|exhale}} to damage a target.
*You don't need [[naphtha]] or other accessories to use this spell, just the command.
*Using either command triggers a slightly flexible cooldown period before they can be used again and does not end the spell.
*Timer varies with skill and is already lower than the normal cooldown period due to the [[Magical feats|Targeted Mastery feat]].
*<s>The commands can be used as many times as the cooldown period allows before the duration wears off. There is no hard limit.</s> The spell can be used up to 6 times, dependent on the mana used in the cast and your cooldown speed
*The accuracy of the Dragon's Breath spell behaves as if fully targeted.
