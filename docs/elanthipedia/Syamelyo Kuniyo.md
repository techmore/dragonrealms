==Notes==
* Guild Leader [[Paglar]] in Boar Clan teaches this spell.
* Affects both arrows when paired with [[Dual load|dual loading]].
* There is a five minute cooldown before it can be used against the same target. The cooldown will reset when a player target leaves the room before the Ranger does. There is now messaging when a target-specific cooldown expires.
* SK's elemental damage will not apply if the arrow already has elemental damage of any kind, or if the target creature is immune to the elemental damage type SK is trying to apply. (If the target is immune to cold damage, it will not change to cold.)
* Damage type can be modified by the metaspell [[Electrogenesis]], converting it from cold to electric.
