Once prepared, flame shockwave will automatically be applied to each cast of shockwave until it expires.

At 300 Elemental Magic / 200 Targeted / 30 in all mental stats, one preparation of FLS lasted roughly 25 minutes. (Testing further)

Similar to some other metaspells, Flame Shockwave does not appear in your active spells window or show up when using PERC. 

This effect cannot be released using the RELEASE command.
