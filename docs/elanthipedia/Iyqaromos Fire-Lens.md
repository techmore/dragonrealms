* Alters the quality and number of beams of [[Burn]] increasing the accuracy and damage based on the number of additional celestial objects available. This is a boost to Burn's single strike attack and does not change it to a multistrike attack.
* One brilliant beam is produced for every bright celestial object ([[Sun]], [[Xibar]], [[Yavash]]) in the sky.
* Brilliant beams are converted to black-core beams when [[Katamba]] is up. This provides the same increase as an additional beam from a bright celestial object.
