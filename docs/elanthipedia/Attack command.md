# Attack command

_Automatically mirrored from Elanthipedia (2026-08-12)._

A simplistic combat [[page type is::command]] that uses a balance-neutral combat combo based on your weapon type.  When used with the {{tt|LEFT}} keyword, it uses your offhand to make the attack.

Attack will attack whatever you're facing, automatically face the next target, and automatically advance/engage if not at melee. 


==Syntax==
* {{tt|ATTACK}} ''<target> <body part>''
* {{tt|ATTACK LEFT}} ''<target> <body part>''
